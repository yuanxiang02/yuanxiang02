## Featured work

### VDE Bench — Visual Document Editing

A bilingual benchmark for instruction-guided editing of dense document images. VDE Bench includes 3,506 text and table editing examples, with region-level and full-page evaluation of text correctness, structural fidelity, and visual preservation.

Listed in the [Hugging Face official benchmark directory](https://huggingface.co/datasets?benchmark=benchmark%3Aofficial): 57 official entries, compared with 8,781 benchmark-tagged datasets in the November 2026 directory snapshot.

[arXiv](https://arxiv.org/abs/2602.00122) · [GitHub](https://github.com/zion-zion-zion/VDE-Bench) · [Hugging Face](https://huggingface.co/datasets/hongzhuyi/VDEBench)
